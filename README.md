# RIVET SHIFT

**リベットシフト — 街をつなぐ橋づくり。**

街の運河に橋を架け、車を向こう岸まで渡す物理パズルです。部材は固定長で、補強の形と本数を自分で考えて組み立てます。荷重が集中すると部材が破断し、橋が崩れます。

## 遊び方

このフォルダをダウンロードし、`index.html` をブラウザで開いてください。左パネルのプルダウンでステージを切り替えます。

| ステージ | 運河の幅 | 道路・木材の固定長 | 車 | 車の合計重量 |
|---|---:|---:|---:|---:|
| 01 リバーサイド | 25m | 5m | 1台 | 850kg |
| 02 コンボイライン | 37.5m | 7.5m | 3台 | 2,550kg |

両ステージとも道路は5枚です。ステージ2では5m間隔で走る車3台の前後輪から、同時に橋へ荷重を加えます。3台すべてが完全に右岸へ渡るとクリアし、1台でも落水すると失敗します。

道路を5クリックで配置したら、木材を選び、接合点から好きな向きにつないで補強します。角度は15°刻みです。木材の重量は1mあたり14kg、道路は1mあたり13kg、非固定の接合点は1個8kgとして自重を計算します。画面には自重と車の合計重量を表示します。

建設の高さ制限はありません。橋の下にも組めます。予算は目安で、超過しても部材を増やせます。護岸の内部を通る部材は配置できません。

## 操作

- Space＋ドラッグ、矢印キー、WASD、「✋ 移動」、中ボタンで移動できます。2本指のピンチ・パンにも対応しています。
- ホイールでカーソルを中心にズームします。Fキーまたはダブルクリックで全体表示に戻ります。
- 選択ツールでドラッグすると木材を範囲選択します。Shiftで追加、Ctrl+Aで木材を全選択します。
- 右クリック、Delete、または「選択を削除」で部材を消せます。
- Ctrl+ZでUndo、Ctrl+YまたはCtrl+Shift+ZでRedoします。履歴は100件です。
- Ctrl+C／X／Vでコピー・切り取り・貼り付けします。貼り付け中にHで左右反転、Escでキャンセルします。
- 走行中はSpaceで一時停止、[／]で速度変更できます。0.1〜8倍速と1コマ送りに対応しています。
- 「ぐるっと見る」で回転できます。「編集に戻る」で正面へ戻ります。

部材の負荷は青→緑→黄→橙→赤で表示します。「力の種類」では引張を青、圧縮を赤で示します。最初の破断位置には赤いリングが出て、結果画面から破断の0.5秒前を0.25倍速で見直せます。

## 保存と音

設計とベスト記録はステージごとに自動保存します。以前の「谷越えブリッジ」「運河の架け橋」で保存したステージ1の設計も読み込めます。JSONの書き出し・読み込みも可能です。別のステージのJSONを読み込むときは、先に対象ステージへ切り替えてください。

ブラウザ保存は端末の設定で消える場合があるため、提出・共有には「設計を書き出す」を使ってください。

効果音とBGMはWebAudioで合成します。音の設定から個別に音量を調整できます。BGMはそのページで「BGMをつける」を押すと始まります。

## 実装と検証

HTML、CSS、ゲームのJavaScriptを `index.html` にまとめています。Three.js r170を `vendor/` に同梱し、ファイルを直接開く場合にはHTML内のオフライン版を使用します。

物理は2DのXPBDトラス、表示はThree.jsの3Dです。各車輪の荷重を道路の両端へ配分します。物理の刻みは速度設定にかかわらず一定です。水面を通過した部材はさらに落下し、水面下の自重も接合先へ伝わります。

Node.js 22以降で、追加パッケージなしで実行できます。

```sh
node test/core.test.js
node test/bugs.test.js
node test/stages.test.js
node test/runtime.test.js
node test/runtime.test.js 2
node test/package.test.js
```

ステージ1のトラス走破、道路だけの自重破断、過負荷による崩壊、0.1〜8倍速の再現性に加え、ステージ2の3台分の荷重伝達・全車の成功判定・1台落水時の失敗・ステージ別保存を検証します。ステージ2は一段のトラスでは破断し、上下にトラスを組んだ検証用の橋では3台が渡れました。

UIテストは実際のThree.jsの座標計算と操作ハンドラを使い、DOM、WebGLの描画先、音声機器を代替しています。実機での見た目・聴感・フレームレートは別途確認が必要です。
